# 小昭拍号码（ParkPhone）

对着电话牌拍一张，App 离线识别出号码，确认标题和号码后存进记录，方便管理和再次拨打。

## 功能
- **拍照识别**：CameraX 取景拍照，ML Kit 中文文字识别（模型打包在 APK 内，全程离线，无需谷歌服务框架）
- **手动输入**：不方便拍照时点快门左侧「手动输入」，系统键盘打字或从剪贴板一键粘贴，实时提示号码类型
- **双击改号**：记录列表里双击（两下间隔小于 0.4 秒）某条记录的号码即可修改，预填原号方便微调；分组、拨打次数、颜色、备注全部保留，与已有号码重复仅提醒不拦截
- **号码提取**：自动从识别文本中筛出手机号 / 带区号座机，多个候选时可手动修改
- **记录分组**：按「标题 ｜ 日期」分组展示，同一天同一地点的号码自动归组；拍摄确认时可一键选用历史标题
- **拨打统计**：每次点「拨打」自动 +1，列表显示已拨次数（只拉起系统拨号盘，不申请通话权限）
- **三色标记**：每条记录可点选蓝 / 绿 / 橙三种颜色圆点，条目左侧同步显示色条，再点同色取消
- **备注**：小窗编辑，内置快捷标签（无人接听 / 已处理 / 稍后再拨 / 态度差），标签支持长按改名、删除、新增
- **隐藏区**：列表长按一条记录 3 秒可将其隐藏；连点页面标题 5 次 → 输入 4 位密码（首次为设置密码）进入深色隐藏区，功能与正常列表一致；返回键一键退出
- **导出表格**：正常区与隐藏区各自独立导出 .xlsx（列：标题、日期、号码、拨打次数、颜色标记、备注），可保存到自选位置或直接分享；隐藏区导出文件名标注「隐藏名单」
- **本地存储**：所有数据与密码只保存在手机本机，不联网上传

## 技术栈
- Kotlin + 传统 View（ViewBinding）
- CameraX 1.3.4 / ML Kit text-recognition-chinese 16.0.1
- xlsx 由零依赖内置生成器直接拼 OOXML（zip + XML），不引入 Excel 库
- minSdk 26（Android 8.0+），targetSdk 34

## 本地开发
用 Android Studio（Hedgehog 及以上）直接打开本目录即可同步 Gradle 并运行。

## GitHub Actions 云端编译 APK
本仓库自带 `.github/workflows/android.yml`：

1. 在 GitHub 新建仓库并把本目录推送上去
2. 仓库页面 → **Actions** 页签会开始构建（push 到 main/master 自动触发，也可以手动 Run workflow）
3. 构建完成后，点开这次运行 → 最下方 **Artifacts** 里下载 `park-phone-debug`
4. 解压得到 `app-debug.apk`，传到手机安装（调试签名，安装时允许"未知来源"）

> 仓库根目录没有提交 gradle wrapper，工作流会在云端自动生成，本地开发不受影响。

## 已知说明
- 调试版 APK 未做代码混淆与正式签名
- 隐藏区密码只存本机，忘记无法找回（清除应用数据会连记录一起丢失）
- 识别准确度取决于照片清晰度，建议贴近号码牌、避免反光
